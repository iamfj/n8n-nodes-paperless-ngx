# Changelog

All notable changes to this project are documented here. Entries below the first release heading
are generated by `auto-changelog` during `npm run release`, which prepends to this file rather than
creating it.

## 0.1.0

First release.

### Added

- Paperless-ngx credential with base-URL normalization, API-token auth, an API-version pin or
  `Auto`, and a connection test against `/api/profile/`.
- **Document** — get, get many (with filters), download the original or the archived PDF, update,
  and delete.
- **Note** — list, add and delete notes on a document.
- **Correspondent**, **Tag**, **Document Type** and **Storage Path** — create, get, get many,
  update, delete, with dropdown pickers wherever a document references them.
- **Document upload** — posts to the Consumption pipeline and, by default, waits for the task to
  finish and returns the resulting document rather than a task ID.
- API v9 and v10 support, negotiated per request via the `Accept` header with automatic fallback.
- Every operation exposed as an AI-agent tool.
