## 0.1.0 (2026-08-12)

Initial release.

### Features

* **archive:** document get, get many, update, delete and download (original, archived or thumbnail)
* **archive:** document notes — create, get many and delete
* **ingestion:** document upload with the consumption task it starts
* **taxonomy:** correspondents, tags, document types and storage paths — create, get, get many,
  update and delete, plus load options for every one of them
* **credentials:** Paperless-ngx API credentials with a live test request
* **shared:** capability-based handling of Paperless API versions 9 and 10
